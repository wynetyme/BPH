# Reference audit for a mechanically faithful Roblox game

Read `docs/reference-matrix.md`. For the requested feature, distinguish (a) official published description, (b) observed in provided gameplay, (c) inferred hypothesis. Extract timing, costs, probabilities, stats, input steps, dependencies, and UI state transitions only where directly evidenced. Make a tiny acceptance test table and update the matrix. Any unobserved value must remain `UNKNOWN` or an explicitly labeled configurable placeholder. Do not silently use protected audio, sprites, illustrations, names or copy.
