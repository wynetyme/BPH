# Packvania

Original Roblox tower-defense pack game. The structure follows Booster Pack Heroes: open packs, place heroes, survive waves, spend Mastery, and keep an optional Robux pack beside the earned ones. The cards, courtyard, enemies, and relics are Packvania's own.

Live Robux purchases stay off. Product `3732907303` must be taken off sale in Creator Hub before any publish. The server does not run outside Studio.

## Play

Sync this repo into the Packvania place with Rojo (`default.project.json`), then press Play in Studio. You start with 30 coins in the moon courtyard. Open a Night Pack, place a Grave Warden on the glowing pad, and press Battle.
